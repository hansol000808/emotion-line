# 감정의 선

**Draw Your Emotion — 2026 Graduation Exhibition**

**[전시 체험하기 →](https://hansol000808.github.io/emotion-line/emotion_line.html)**

마우스나 터치로 그린 선을 도형으로 인식하고, 그 도형에 연결된 감정을 색·빛·문구·소리로 표현하는 웹 기반 인터랙티브 전시 프로젝트입니다. 관람객이 그리는 원, 하트, 삼각형, 위로 쓸기, X자가 서로 다른 감정의 세계로 이어집니다.

- 저장소: [hansol000808/emotion-line](https://github.com/hansol000808/emotion-line)
- 시작 파일: `emotion_line.html`
- 구현: HTML, CSS, JavaScript, Canvas 2D, Web Audio API

## 작품 구성

| 제스처 | 감정의 세계 | 주요 색상 | 화면 문구 |
| --- | --- | --- | --- |
| 원 | 평온 | 파랑 | 지금 이 순간 |
| 하트 | 사랑 | 분홍 | 사랑하는 모든 것에게 |
| 삼각형 | 우울 | 회청색 | 괜찮지 않아도 괜찮아 |
| 위로 쓸기 | 기쁨 | 노랑 | 환희의 빛 |
| X자 | 분노 | 빨강 | 타오르는 감정 |

제스처가 인식되면 배경과 이후에 그리는 선의 색이 바뀌고, 파티클과 전환 효과, 감정별 문구와 멜로디가 나타납니다. 감정 표현은 도형에 미리 지정된 연출을 따릅니다.

## 주요 기능

- **자유로운 그리기:** 마우스 드래그와 터치 입력으로 캔버스에 선 그리기
- **도형 인식:** 입력 좌표의 모양을 분석하는 규칙 기반 제스처 판별
- **감정별 연출:** 배경, 선 색상, 파티클, 메시지와 전환 효과 변경
- **실시간 사운드 합성:** 그리기 효과음, 전환 효과음과 감정별 멜로디
- **입력 안내:** 시작 화면의 도형 예시와 전시 화면의 제스처 힌트
- **캔버스 지우기:** 저장된 획을 지우고 멜로디를 중단한 뒤 기본 배경으로 전환

그림과 상태는 현재 페이지의 메모리에 유지됩니다. 새로고침 후 복원하거나 그림을 파일로 내보내는 기능은 구현되어 있지 않습니다.

## 체험 방법

1. 페이지를 열고 **감정을 그리기 시작하다 →** 버튼을 누릅니다.
2. 마우스 버튼을 누른 채 드래그하거나 손가락으로 화면에 도형을 그립니다.
3. 마우스 버튼이나 손가락을 떼면 해당 획을 분석합니다.
4. 도형이 인식되면 감정의 세계가 바뀝니다.
5. 다시 시작하려면 왼쪽 아래의 **캔버스 지우기** 버튼을 누릅니다.

원·하트·삼각형은 한 획으로 그리고 시작점과 끝점을 가깝게 닫습니다. 위로 쓸기는 아래에서 위로 충분한 길이로 그립니다. X자는 서로 교차하는 두 대각선을 연속해서 그리며, 두 획의 완료 시점 간격이 2초 이내여야 합니다.

현재 판별기는 입력 점 수와 도형 크기 등의 조건을 사용하므로 너무 작거나 빠르게 그린 도형은 인식되지 않을 수 있습니다. 같은 감정이 연속으로 인식되면 전환 연출과 멜로디를 다시 시작하지 않습니다.

사운드는 시작 버튼이나 그리기 입력 시 AudioContext를 생성하는 방식입니다. 소리가 들리지 않으면 기기와 브라우저 탭의 음소거 상태를 확인하세요. 앱 내부 음량 조절 기능은 없습니다.

## 로컬에서 실행하기

별도의 빌드나 npm 패키지 설치 없이 정적 파일 서버로 열 수 있습니다. 아래 예시는 Git과 Python 3가 설치된 환경을 기준으로 합니다.

### 1. 저장소 내려받기

```sh
git clone https://github.com/hansol000808/emotion-line.git
cd emotion-line
```

GitHub의 **Code → Download ZIP**으로 내려받아 압축을 풀어도 됩니다.

### 2. 서버 실행

`emotion_line.html`이 있는 디렉터리에서 실행합니다.

Windows:

```powershell
py -3 -m http.server 8000 --bind 127.0.0.1
```

macOS / Linux:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

### 3. 전시 페이지 열기

[http://127.0.0.1:8000/emotion_line.html](http://127.0.0.1:8000/emotion_line.html)에 접속합니다. 시작 파일 이름이 `index.html`이 아니므로 경로에 `emotion_line.html`을 포함합니다.

서버를 종료하려면 터미널에서 `Ctrl+C`를 누릅니다. Canvas 2D와 Web Audio API를 지원하는 브라우저가 필요하며, Google Fonts를 불러오려면 인터넷 연결이 필요합니다.

## 기술 구성

| 기술 | 역할 |
| --- | --- |
| HTML / CSS | 시작 안내, 감정 메시지, 화면 레이어와 전환 스타일 |
| JavaScript | 입력 처리, 도형 판별, 상태 전환 |
| Canvas 2D | 그린 선과 파티클 렌더링 |
| Web Audio API | 오실레이터·게인·필터·딜레이를 이용한 소리 합성 |
| requestAnimationFrame | 파티클과 커서 애니메이션 |
| SVG | 안내 화면과 힌트의 도형 아이콘 |
| Google Fonts | Cormorant Garamond, Noto Sans KR |

외부 JavaScript 프레임워크나 서버 API를 사용하지 않습니다. 효과음과 멜로디는 별도 오디오 파일을 재생하는 대신 코드에 정의된 음표와 주파수로 합성합니다.

## 파일 구조

```text
emotion-line/

└── emotion_line.html       # 화면, 스타일, 입력·인식·렌더링·사운드 구현
```

## 동작 흐름과 주요 코드

```text
마우스 / 터치 입력
  → startDraw() / moveDraw()
  → endDraw()
  → recognizeGesture()
  → X자 후보는 checkCrossFromRecent()로 추가 판별
  → enterWorld()
  → 배경·메시지·파티클 변경 및 사운드 재생
```

| 구성 요소 | 역할 |
| --- | --- |
| `WORLDS` | 감정별 색상, 문구, 주파수, 멜로디와 템포 설정 |
| `NOTE_FREQ` | 음 이름을 주파수로 변환하는 테이블 |
| `startDraw()` / `moveDraw()` / `endDraw()` | 획의 좌표 수집, 선 그리기와 판별 요청 |
| `recognizeGesture()` | 닫힘 여부, 가로세로 비율, 직선성, 반지름 분산과 모서리 등을 이용한 판별 |
| `checkCrossFromRecent()` | 최근 두 대각선의 시간 간격, 교차와 방향 관계로 X자 판별 |
| `enterWorld()` | 현재 감정과 화면 연출 변경 |
| `playDrawSound()` / `playTransitionSfx()` | 그리기·전환 효과음 합성 |
| `playMelody()` / `stopMelody()` | 감정별 멜로디 예약 재생과 중단 |
| `spawnParticle()` / `spawnBurst()` / `updateParticles()` | 파티클 생성과 프레임별 갱신 |
| `resize()` / `redrawAllStrokes()` | 캔버스 크기 변경과 저장된 획 다시 그리기 |

그리기와 파티클은 각각 `draw-canvas`, `particle-canvas`에서 처리합니다. `allStrokes`는 완료된 획을, `recentStrokes`는 최근 최대 5개 획을 보관합니다.

## 연출 수정하기

변경할 내용은 모두 `emotion_line.html`에서 찾을 수 있습니다.

| 수정할 내용 | 위치 |
| --- | --- |
| 시작 안내와 제스처 힌트 | `#guide`, `.gesture-hints` |
| 감정 이름과 메시지 | `WORLDS`의 `name`, `message`, `sub` |
| 배경·선·파티클 색상 | `WORLDS`의 `bg1`, `bg2`, `lineColor`, `particleColor` |
| 전환 효과음 | `WORLDS`의 `freq`, `waveform` 및 `playTransitionSfx()` |
| 멜로디와 속도 | `WORLDS`의 `melody`, `melodyTempo` |
| 도형 판별 조건 | `recognizeGesture()`, `checkCrossFromRecent()` |
| 파티클 움직임 | `spawnParticle()`, `spawnBurst()`, `updateParticles()` |
| 화면 배치와 글꼴 | `<style>` 블록 |

새 제스처를 추가하려면 `WORLDS` 설정뿐 아니라 판별 함수와 화면의 안내도 함께 수정해야 합니다.

## 현재 상태와 개선 과제

이 README는 2026-09-23 기준 `main` 브랜치의 소스를 바탕으로 작성했습니다. 브라우저 실행, 인식 정확도 측정과 장시간 구동 검증은 수행하지 않았습니다. 현재 저장소에는 자동화 테스트나 CI 설정이 없습니다.

### 현재 제약

- **인식 정확도:** 임계값과 순차 조건으로 도형을 판별합니다. 원·하트·삼각형의 조건이 겹칠 가능성이 있어 입력 모양에 따른 오인식 검증이 필요합니다.
- **장시간 사용:** 지우기 전까지 완료된 획과 좌표가 계속 누적되며, 획 수 제한이나 무입력 자동 초기화가 없습니다.
- **기기 대응:** 캔버스 크기는 화면 크기를 따르지만 `devicePixelRatio` 보정과 저장된 좌표의 비례 변환은 구현되어 있지 않습니다.
- **사운드 제어:** AudioContext의 중단 상태 복구와 앱 내부 음소거·음량 조절 기능이 없습니다.
- **입력과 접근성:** 마우스·터치 중심이며, 키보드로 감정을 선택하는 대체 조작이나 모션 감소 설정은 없습니다.
